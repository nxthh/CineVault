# CineVault

**Discover movies and TV shows, all in one place.**

CineVault is a free movie and TV show streaming website built with vanilla HTML, TailwindCSS, and TypeScript. It provides a simple, responsive interface for discovering movies and TV shows, exploring details, and watching available content without requiring an account.

**Live Demo:** [cinevault-jet-eight.vercel.app](https://cinevault-jet-eight.vercel.app/)

**Repository:** [github.com/nxthh/CineVault](https://github.com/nxthh/CineVault)

## Features

- **Free Access** — Browse and watch available content without registration or login.
- **Movie Discovery** — Explore movies and discover popular titles.
- **TV Show Discovery** — Browse TV shows and explore available series.
- **Content Details** — View information about movies and TV shows.
- **Streaming Integration** — Access streaming sources through VidSrc.
- **TMDB Integration** — Retrieve movie and TV show metadata, including titles, posters, and other details.
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Dark and Light Themes** — Switch between themes for a comfortable viewing experience.
- **Search and Filtering** — Find content more easily.
- **No Account Required** — No login, registration, or subscription is required to use the website.

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and semantic markup |
| TailwindCSS | Styling, layout, and responsive design |
| TypeScript | Interactive functionality and application logic |
| TMDB API | Movie and TV show metadata |
| VidSrc | Third-party streaming integration |
| Vercel | Website deployment and hosting |

CineVault is built with vanilla HTML, TailwindCSS, and TypeScript without a frontend framework such as React or Vue.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) and npm
- [Git](https://git-scm.com/)
- A code editor of your choice

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/nxthh/CineVault.git
   ```

2. Navigate to the project directory:

   ```bash
   cd CineVault
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server using the script defined in `package.json`:

   ```bash
   npm run dev
   ```

   If your project does not define a `dev` script, check `package.json` for the available commands.

5. Open the local URL shown in your terminal.

> **Note:** The exact setup commands may vary depending on the project's current build configuration.
